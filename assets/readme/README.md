# Capturas do README — versão 1.0.0

Produzidas em 25/11/2026 a partir da interface real atual, no Chromium com viewport de smartphone de 430 × 932 pixels e densidade 2. Os arquivos finais têm **860 × 1864 pixels**, em WebP, com metadados removidos e qualidade 90. Não são fotografias da tela de um aparelho Android.

Foi utilizado um perfil temporário de navegador, com banco IndexedDB isolado: três cafés fictícios (Horizonte, Aurora e Ipê), doze preparos demonstrativos e três reflexões fictícias. Os nomes de origem/produtor também são demonstrativos. A biblioteca oficial foi incorporada pelos mecanismos reais da aplicação; não foram alterados componentes, estilos ou catálogo para as capturas.

As imagens associadas aos cafés vieram dos assets públicos existentes do próprio aplicativo (`public/images/coffees-hero.png` e `public/images/journey-cup.png`). São ilustrações demonstrativas; não são fotografias pessoais ou novas imagens obtidas de terceiros. As imagens do ZIP de receitas sem autorização de redistribuição não foram usadas.
