As quatro imagens Android são capturas reais do viewport do smartphone por ADB. O seletor SAF abriu, mas os toques ADB foram bloqueados por INJECT_EVENTS: seleção e conclusão de salvamento externo nesse seletor não foram automatizadas. Os ZIPs de teste entraram pelo handler comum do formulário via CDP; persistência, fotos, restauração, importação e preparo usaram as pontes nativas reais. O menu de compartilhamento real abriu, sem envio. A instalação principal permaneceu 0.6.4, sem atualização; as 16 fotos conservaram seus hashes. O hash do banco principal diferiu ao final, conforme a evidência Android.
