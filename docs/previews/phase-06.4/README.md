# Capturas e validação da Fase 06.4

Dados fictícios em perfil temporário do Chrome, origem localhost isolada e fuso America/Sao_Paulo. As fotografias ilustrativas são assets existentes do projeto. Nenhum dado real foi usado ou alterado.

Matriz: 320/390/768/1440 px × temas Claro/Escuro × escalas 85/100/115% × oito telas/estados = **192 combinações**. As capturas abaixo mostram 390 px/100%, 320 px/115% e 1440 px/115% em ambos os temas. Diálogos são capturados no viewport; outras telas, em página inteira.

A navegação fixa pode aparecer na posição do viewport inicial nas capturas de página inteira, como nas fases anteriores. O formulário é rolável; a captura do viewport mostra somente sua parte inicial.
